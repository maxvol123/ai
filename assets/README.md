# Карточка #DONTSKIP

Рабочий фон: **`dontskip-background.png`**, 1200 × 1200, без текста и логотипа. В нём сохранена планета из исходной картинки; горизонт опущен ниже логотипа и даты. **`tikrd-logo.png`** — отдельный прозрачный логотип. Старый `dontskip-template.png` оставлен как исходник. Если прежняя настройка указывает на него или на его точную копию под другим именем, рендерер автоматически использует чистый фон и пишет предупреждение в журнал.

Свои квадратные фоны и прозрачные логотипы задаются через `DONTSKIP_TEMPLATE_PATH` и `DONTSKIP_LOGO_PATH`. Фон масштабируется до 1200 × 1200. Явно заданный отсутствующий файл или неквадратный фон приводят к ошибке. Без встроенного фона используется программная планета, без логотипа — текст TIKRD AI NEWS.

Сетка и типографика заданы в `LAYOUT` и `TYPE` в `src/services/dontskip-image.ts`:

| Элемент | Координаты | Типографика |
| --- | --- | --- |
| Границы заголовков | x = 110 / 900 | ширина 790 px, колонка 01/02 зарезервирована отдельно |
| Kicker первой новости | x = 110, y = 125 | 24 px, 700, интервал 5 px, #7A8A84 |
| Заголовок первой новости | x = 110, y = 190 / 255 | 62 px, 800, #F5F5F5 |
| #DONTSKIP | x = 110, y = 430 | 88 px, 900, белый + #28F5A5 |
| Kicker второй новости | x = 110, y = 600 | как у первой |
| Заголовок второй новости | x = 110, y = 665 / 730 | 51 px, 750, #F5F5F5 |
| Акценты слева | x = 92, y = 110 / 585 | 4 × 155 / 150 px, зелёные |
| Центр логотипа | x = 600, y = 960 | до 240 × 125 px |
| Дата UTC | x = 600, y = 1095 | 24 px, 500, #A6B2AC |

Координаты текста — базовые линии. Они имеют приоритет над номинальным `lineHeight` из TYPE. Шрифт DejaVu Sans должен быть установлен в среде запуска.

Сохранённые displayHeadline перед повторным использованием проверяются по текущей ширине. Если текст из старой широкой сетки уже не помещается, для выбранной пары генерируется новый короткий вариант до рендеринга и публикации.

Для двух выбранных статей модель отдельно пишет `kicker` и короткий `displayHeadline` (до 48 символов и 8 слов). Исходный title и одобренный заголовок поста служат контекстом. Перенос по измеренной ширине букв ограничен двумя строками; допустимо уменьшение размера максимум на 6 px. Не помещающийся текст отклоняется без обрезания. Сгенерированные поля сохраняются в кандидате перед рендерингом и используются повторно при его ошибках. Подпись со ссылками сохраняет исходные названия статей.

Превью без API и отправки в Telegram:

```sh
npm run digest:preview
npm run digest:preview -- "CHATGPT STORAGE SCALES FOR 1B USERS" "GMAIL DATA MAY POWER AD TARGETING" "OPENAI" "GOOGLE"
```
