# Шаблон #DONTSKIP

Загрузите исходник в эту папку под именем **`dontskip-template.png`**.

Размер: **1200 × 1200 пикселей**, формат PNG. Файл используется как основа без изменения размера. Фон, надпись #DONT SKIP, планета и логотип должны быть уже на шаблоне.

Оставьте свободное место для текста, который бот накладывает автоматически:

- Первый заголовок: по центру, базовые линии на y = 260, 330, 400.
- Второй заголовок: по центру, базовые линии на y = 780, 850, 920.
- Дата UTC: по центру в самом низу, базовая линия на y = 1180 (20 px от нижнего края).

Заголовки белые, размер шрифта 58 px, максимум три строки. Дата серо-зелёная, моноширинный шрифт Consolas (либо Liberation Mono / DejaVu Sans Mono), 26 px, межбуквенный интервал 1.5 px. Центр текста: x = 600.

После загрузки файл подхватится при следующей генерации. Пока файла нет, используется прежняя программная картинка. Для другого расположения задайте `DONTSKIP_TEMPLATE_PATH`. Явно заданный отсутствующий файл или шаблон другого размера приводят к ошибке генерации.
